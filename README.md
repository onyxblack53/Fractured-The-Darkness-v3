# F.C.D v3.3 — Modular Architecture

Structural refactor of the working v3.2.1 build.

- index.html — shell/markup only
- css/game.css — UI and layout
- js/creator.js — creator flow/state
- js/characters.js — bloodlines, hybrid visuals, hero rendering
- js/classes.js — class armor/weapons
- js/player.js — spawn/movement/combat
- js/enemies.js — enemy rendering
- js/world.js — Broken Castle environment
- js/render.js — canvas setup
- js/controls.js — touch controls
- js/main.js — draw/game loop
- assets/ — reserved for future sprites/art

No gameplay redesign is intended in this release.
